# Outbreak: Protocol Zero

Гравці-любителі сюжетних екшенів зможуть пройти лінійний 15-хвилинний 2D-шутер із пошуком сюжетних КПК-записок та розкриттям таємниці витоку вірусу, що дає цілісну короткометражну історію з розв'язкою без потреби витрачати десятки годин на проходження великих RPG.

### Аналоги:
1. **Alien Shooter** (https://sigma-team.net) — На відміну від аркадного Alien Shooter, де повністю відсутній сюжет і є лише нескінченний відстріл монстрів, Outbreak пропонує текстові діалоги, сюжетні записки та розкриття лору світу.
2. **Hotline Miami** (https://store.steampowered.com/app/274170/Hotline_Miami) — На відміну від складного Hotline Miami з абстрактною подачею історії та хардкорним геймплеєм, наш проєкт має чіткий послідовний сюжет і зрозумілу шкалу здоров'я.
3. **Dead Space** (https://www.ea.com/games/dead-space) — На відміну від вимогливої до ПК 3D-гри Dead Space, наш продукт є легким 2D-додатком, який працює на будь-якому комп'ютері без потреби встановлення високих системних вимог.
